2Use It With OpenClaw (Recommended)

OpenClaw is a free app that lets you use AI assistants on your computer with your own API keys. Here's how to connect NiceGuyAPI:

Step 1: Install OpenClaw

# Install OpenClaw (requires Node.js 18+) npm install -g openclaw # Or download the desktop app from: # https://docs.openclaw.ai

Step 2: Set your NiceGuyAPI key as your AI provider

# In your terminal, set these environment variables: export OPENAI_API_KEY="gsk_live_your_key_here" export OPENAI_BASE_URL="https://niceguyapi.onrender.com/v1" # Then start OpenClaw — it now uses NiceGuyAPI! openclaw

Alternative: If you don't want to use terminals, just edit your OpenClaw config file and add your NiceGuyAPI key and base URL there. Look for the "provider" or "API" settings.

💡 NiceGuyAPI is fully OpenAI-compatible. Any tool that works with OpenAI's API works with NiceGuyAPI — just swap the key and URL.

3Use With Any App or SDK

NiceGuyAPI works with any programming language and any SDK that supports OpenAI. Here are examples:

Python:

from openai import OpenAI client = OpenAI( api_key="gsk_live_your_key_here", base_url="https://niceguyapi.onrender.com/v1" ) response = client.chat.completions.create( model="deepseek/deepseek-v4-flash:free", messages=[{"role": "user", "content": "Hello! Who are you?"}] ) print(response.choices[0].message.content)

JavaScript:

const response = await fetch('https://niceguyapi.onrender.com/v1/chat/completions', { method: 'POST', headers: { 'X-API-Key': 'gsk_live_your_key_here', 'Content-Type': 'application/json', }, body: JSON.stringify({ model: 'deepseek/deepseek-v4-flash:free', messages: [{ role: 'user', content: 'Hello!' }], }), }); const data = await response.json(); console.log(data.choices[0].message.content);
